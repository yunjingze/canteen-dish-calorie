# 永久固定地址：三条路线

"固定地址"的意思是：**不管重启多少次电脑、换不换 Wi-Fi，别人收藏的那条链接永远能打开**。
临时隧道（`scripts/start_public.ps1` 用的 Cloudflare 快速隧道）做不到这一点——它每次启动都随机分配 `xxx.trycloudflare.com`。

下面三条路线都能做到"地址不变"，按**推荐程度**排序。三条路线都不需要公网 IP、不需要在路由器上开端口，因为都是"本机主动往外连"的反向隧道。

| 路线 | 要买域名吗 | 地址长什么样 | 费用 | 首访有提示页吗 | 适合 |
|---|---|---|---|---|---|
| **A. Cloudflare Named Tunnel** | 要（约 30–60 元/年） | `https://food.你的域名` | 域名钱，隧道免费且不限流量 | 没有 | 长期用、要给老师/同学收藏、以后上小程序 |
| **B. Tailscale Funnel** | 不要 | `https://机器名.你的tailnet.ts.net` | 免费 | 没有 | 不想买域名，地址不好看也能接受 |
| **C. ngrok 免费固定域名** | 不要 | `https://xxx.ngrok-free.app` | 免费（1 GB/月） | 有（浏览器首次访问） | 只想 5 分钟搞定、偶尔演示 |

> 三条路线的前置条件都一样：电脑开着、不睡眠、后端服务在 8000 端口跑着。电脑一关，再"永久"的地址也会 502。

---

## 方案 A：Cloudflare Named Tunnel + 自己的域名（推荐）

原理：在 Cloudflare 上建一条**有名字的隧道**（Named Tunnel），再把自己的子域名用 CNAME 指到这条隧道。域名和隧道都是持久的，所以地址永久固定；隧道进程断线重连后还是同一个地址。

### A0. 准备

1. 一个域名。阿里云/腾讯云/Namesilo/Cloudflare Registrar 都行，`.top`/`.xyz` 首年往往 10–30 元，`.com` 约 60–80 元/年。
2. 一个免费 Cloudflare 账号（注册只要邮箱）。
3. 本项目的 `tools/cloudflared.exe`（没有的话脚本会自动下载）。

> 中国大陆注册商买的域名可以正常托管到 Cloudflare，**浏览器访问不需要 ICP 备案**。备案只在"网站放在中国大陆服务器"或"微信小程序正式版配置合法域名"时才需要（见小程序指南第 10 节）。

### A1. 把域名托管到 Cloudflare

1. 登录 <https://dash.cloudflare.com> → **Add a site** → 输入你的域名 → 选 **Free** 套餐。
2. Cloudflare 会给你两个 nameserver，例如 `ada.ns.cloudflare.com`、`bob.ns.cloudflare.com`。
3. 回到买域名的网站，把域名的 **DNS 服务器（NS）** 改成这两个。阿里云在"域名控制台 → DNS 修改"；腾讯云在"DNSPod → 域名设置"。
4. 等生效，通常 10 分钟到 2 小时（最长 24 小时）。Cloudflare 后台该域名状态变成 **Active** 就好了。

验证（可选）：`nslookup -type=NS 你的域名` 应该返回 `*.ns.cloudflare.com`。

### A2. 登录隧道（一条命令，点一下浏览器）

```powershell
cd "E:\项目作业\food_project"
.\tools\cloudflared.exe tunnel login
```

浏览器会弹出 Cloudflare 授权页：选中你的域名 → **Authorize**。成功后会在 `C:\Users\13561\.cloudflared\cert.pem` 生成证书。

### A3. 一键创建隧道（脚本）

```powershell
powershell -ExecutionPolicy Bypass -File scripts\setup_cloudflare_tunnel.ps1 -Hostname food.你的域名.com
```

脚本依次做四件事（也可以照着手动做）：

1. `cloudflared tunnel create fooddemo` —— 建隧道，凭据存到 `%USERPROFILE%\.cloudflared\<UUID>.json`；
2. `cloudflared tunnel route dns --overwrite-dns fooddemo food.你的域名.com` —— 自动建 CNAME，把域名指到隧道；
3. 写配置文件 `tools/cloudflared_config.yml`：

   ```yaml
   tunnel: <隧道UUID>
   credentials-file: C:\Users\13561\.cloudflared\<隧道UUID>.json

   ingress:
     - hostname: food.你的域名.com
       service: http://127.0.0.1:8000
     - service: http_status:404
   ```

   （`ingress` 是"哪个域名转发到哪个本地端口"，最后一条 `http_status:404` 是兜底规则，必须有。）
4. `cloudflared tunnel ingress validate` 校验配置。

### A4. 启动

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start_permanent.ps1 -Hostname food.你的域名.com
```

脚本会：检查 8000 端口 → 没起就后台拉起 FastAPI → 前台运行隧道并打印 `https://food.你的域名.com`。开着这个窗口就是"服务在线"，`Ctrl+C` 停止。

也可以完全手动：

```powershell
.\tools\cloudflared.exe tunnel --config tools\cloudflared_config.yml run fooddemo
```

### A5. 开机自启（可选，让地址真正"永久"）

想让电脑一登录就自动恢复服务，用 Windows 任务计划程序跑 `start_permanent.ps1`（会同时起后端和隧道）：

```powershell
$root = "E:\项目作业\food_project"
$action = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File '$root\scripts\start_permanent.ps1' -Hostname food.你的域名.com"
$trigger = New-ScheduledTaskTrigger -AtLogOn
Register-ScheduledTask -TaskName "FoodDemoPermanent" -Action $action -Trigger $trigger -Description "菜品识别演示：后端 + Cloudflare 隧道" -Force
```

或者注册成 Windows 服务（需要管理员权限，电脑不登录也能跑）：

```powershell
# 管理员 PowerShell 里执行；服务以 SYSTEM 身份运行，配置要用绝对路径
.\tools\cloudflared.exe --config "$PWD\tools\cloudflared_config.yml" service install
Start-Service cloudflared
```

> 注意：服务方式读取的是 SYSTEM 账户下的 `.cloudflared` 目录，如果提示找不到凭据，把 `%USERPROFILE%\.cloudflared` 里的 `cert.pem` 和 `<UUID>.json` 复制到 `C:\Windows\System32\config\systemprofile\.cloudflared\`，并把配置里的 `credentials-file` 改成那个绝对路径。

### A6. 验证与排错

```powershell
curl.exe -s https://food.你的域名.com/api/health     # {"ok":true,...}
.\tools\cloudflared.exe tunnel list                 # 能看到 fooddemo，CONNECTIONS 有值
nslookup food.你的域名.com                            # 返回 Cloudflare 的 IP
```

| 现象 | 原因 | 解决 |
|---|---|---|
| Cloudflare 错误 **1033** | 隧道进程没在跑 | 重新运行 A4；或检查任务计划/服务状态 |
| **502 Bad Gateway** | 隧道通了，但本机 8000 没服务 | 先起后端：`scripts\start_demo.ps1` |
| **404**（Cloudflare 页面） | ingress 里没有这个 hostname | 检查 `tools/cloudflared_config.yml` 的 hostname 是否和访问的一致 |
| 域名打不开但 `cloudflared tunnel list` 正常 | DNS 还没生效 / NS 改错 | 等十分钟；确认域名状态是 Active |
| 局域网能开、公网 502 | 服务监听在 `127.0.0.1` 且隧道指向别的端口 | 确认 ingress 的 `service` 端口 = 服务端口 |

### A7. 加访问口令（强烈建议，免费）

固定地址意味着"链接一直有效"，谁拿到都能用。给域名加一层登录最简单的方式是 **Cloudflare Access**：

1. Cloudflare 后台 → **Zero Trust** → **Access** → **Applications** → **Add an application** → **Self-hosted**；
2. 域名填 `food.你的域名.com`，建一条策略：Action = Allow，Include = Emails，填你和老师的邮箱；
3. 保存后，访问者要先输邮箱收验证码，验证通过才能进页面。免费版支持 50 个用户。

不想用 Access 也可以在小程序/网页端加一个共享口令（需要改代码，当前版本没有）。

## 方案 B：Tailscale Funnel（不买域名）

原理：装 Tailscale（一个基于 WireGuard 的组网工具），用 Funnel 把本机端口发布到公网。地址是 `https://<机器名>.<你的tailnet>.ts.net`，只要不删设备/不改机器名就不变。

1. 安装并登录（免费个人版，支持 3 个用户 100 台设备）：

   ```powershell
   winget install --id tailscale.tailscale -e
   ```

   装完打开 Tailscale 登录（Google/GitHub/微软账号都行）。

2. 打开 **HTTPS 证书**：Tailscale 管理后台 → **DNS** → 找到 **HTTPS Certificates** → **Enable**。（Funnel 必须要 HTTPS，第一次开会有几秒签发时间。）

3. 发布端口：

   ```powershell
   tailscale funnel --bg 8000
   tailscale funnel status
   ```

   输出里的 `https://xxxx.tailxxxx.ts.net` 就是固定地址。`--bg` 表示后台常驻，重启机器后自动恢复。

4. 或者用脚本（先确保后端已启动）：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\start_funnel.ps1 -Port 8000
   ```

5. 关闭：`tailscale funnel reset`。

**限制**：地址不好看；`.ts.net` 没有 ICP 备案，**不能用于微信小程序正式版的合法域名**；Funnel 是公开的，任何人拿到链接都能访问；免费版对流量有公平使用限制，不适合大流量。

## 方案 C：ngrok 免费固定域名（最快，但有配额）

原理：ngrok 免费账号可以白嫖一个**固定的二级域名**（`xxx.ngrok-free.app`），把本地端口固定映射过去。

1. 注册 <https://dashboard.ngrok.com/signup>（免费）。
2. 复制 **Your Authtoken**（Dashboard → Getting Started → Your Authtoken）。
3. 第一次运行脚本会自动下载 `tools/ngrok.exe`；先把 token 写进配置：

   ```powershell
   cd "E:\项目作业\food_project"
   .\tools\ngrok.exe config add-authtoken <你的token>
   ```

4. 领取固定域名：Dashboard → **Universal Gateway** → **Domains** → **New Domain**（免费账号可领 1 个），名字随便取，得到 `xxx.ngrok-free.app`。
5. 启动（脚本会打印 `https://xxx.ngrok-free.app`）：

   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts\start_ngrok.ps1 -Domain xxx.ngrok-free.app
   ```

**限制**（免费版）：1 GB/月流量；浏览器第一次访问会弹一个 "You are about to visit..." 提示页（点一下继续；程序调用可加请求头 `ngrok-skip-browser-warning: 1` 跳过）；带宽有限。**适合临时演示，不适合长期挂**。

## 三条路线怎么选

- **要给老师/同学一个能收藏的链接、还想以后上小程序** → A（域名钱是唯一成本，体验最干净）。
- **完全不想花钱** → B（Tailscale Funnel），地址丑一点但稳定、无提示页。
- **今天就要用、懒得折腾** → C（ngrok），五分钟能跑起来，注意配额和提示页。

## 公共注意事项

1. **电脑必须开着且不睡眠**：控制面板 → 电源选项 → 把"睡眠"设为"从不"；笔记本合盖要设"不采取任何操作"。
2. **公网无鉴权**：任何拿到链接的人都能上传图片。演示完就 `Ctrl+C`，或者按 A7 加 Cloudflare Access。
3. **端口一致**：隧道指向的端口必须和 `PORT` 环境变量一致（默认 8000）。改了端口要同步改 ingress 配置/脚本参数。
4. **小程序需要 HTTPS + 备案域名**：A 用自己备案的域名可以满足；B/C 的域名不能用于正式发布（只能开发版/体验版调试）。
5. **上传大小**：手机照片 2–8 MB，三条路线都没问题；识别延迟取决于本机 GPU/CPU，不在隧道上。
