# 这些数字有多稳：置信区间与配对检验

生成脚本：`results/_stats.py`（无 GPU，直接读 `results/_ens_<run>__<split>.npz` 里缓存的每图六视图 logits）
输出：`results/tables/stats.json`

## 方法

- **融合方式**：每张图六个视图（3 种取景 × 水平翻转）的 logits 取平均后 argmax。这是 app `analyse_full` 的融合方式；注意它与 README §5.7 里"单视图 / 翻转 / 五裁剪"三个数字不是同一口径，所以数会比 71.6 略高。
- **置信区间**：对图片做 4,000 次有放回重采样，取 2.5 / 97.5 百分位（percentile bootstrap）。
- **配对检验**：同一批图片上两个模型都跑过，用精确 McNemar（二项检验，p=0.5），报告"只有 A 对"和"只有 B 对"的张数。

## 怎么读这些结果

1. **"六视图 +1.2"这类小幅提升，多数落在噪声里。** E7 比 E4 在 test 上 +1.5 pt（p < 0.0001，5,000 张，可信）；在 canteen 上 +4.3 pt（p = 0.0007，可信）；但在另一个随机抽的代理盘 canteen_s7 上只有 +2.0 pt（p = 0.15，不显著）。方向一致、幅度不稳，是典型的"1,000 张抽样"效应：代理盘的置信区间本身就有 ±2.7 pt 宽。
2. **去重（E7 vs E8）在哪个划分上都不显著**，p 在 0.46–1.00 之间。这与之前"泄漏只值 0.1 pt"的结论一致，可以放心说"去重没有可测的影响"。
3. **五模型集成是唯一稳定显著优于单模型的改动**：test +1.0 pt（p < 2e-4）、canteen +2.8 pt（p = 0.0013）、canteen_s7 +3.4 pt（p = 0.0002）。代价是五倍推理。现在的网页只服务 E7，这是可以摆到"未来工作"里的第一条。
4. **真实照片只有 100 张，区间 ±5 pt**：E7 95.0% 与 test 93.4% 在统计上不可区分，这正好印证"这批是干净网图、不是食堂域"。用它下结论只能看方向，不能看小数点。
5. **门控**：131 张真负样本拒掉 96.9% [93.9, 99.2]，100 张真实菜保留 95.0% [90.0, 99.0]；两个区间不重叠，说明这个否决头确实在做区分而非靠阈值挪动。
